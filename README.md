# Multilingual AI Blog Platform

個人向け多言語ブログプラットフォーム

## Features

- 日本語記事作成
- 英語記事自動生成
- フランス語記事自動生成
- AIタグ生成
- AI SEO生成
- GrapesJS対応
- 多言語対応
- SEO対応

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- TanStack Query
- next-intl
- GrapesJS

### Backend

- Next.js Route Handler
- FastAPI

### Database

- MySQL
- Prisma

### Package Manager

- pnpm
